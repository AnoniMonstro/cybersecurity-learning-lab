#  Networking

Esta seção do meu Cybersecurity Learning Lab é dedicada aos meus estudos sobre Redes de Computadores.

O conhecimento de redes é uma parte fundamental da minha formação em Tecnologia e também possui uma forte relação com a Cibersegurança.

##  Objetivos de estudo

Nesta área, pretendo desenvolver conhecimentos sobre:

* Fundamentos de Redes
* Modelo OSI
* Modelo TCP/IP
* Endereçamento IPv4
* Endereçamento IPv6
* Subnetting
* Protocolos de Rede
* DNS
* DHCP
* TCP e UDP
* Switching e Routing

##  Cisco Packet Tracer

Também utilizarei esta seção para documentar meus estudos e laboratórios realizados utilizando o Cisco Packet Tracer.

Os laboratórios poderão incluir:

* Criação de topologias
* Configuração de dispositivos
* Comunicação entre redes
* Testes de conectividade
* Estudos sobre protocolos
* Simulações de redes

##  Networking and Cybersecurity

Redes e Cibersegurança possuem uma relação muito próxima.

Para compreender melhor a segurança de um ambiente, é importante entender como os dispositivos se comunicam, como os dados trafegam pela rede e quais protocolos estão envolvidos nessa comunicação.

Por isso, o estudo de Networking faz parte da construção da minha base em Cibersegurança.
